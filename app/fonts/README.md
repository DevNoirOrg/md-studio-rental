# Betűtípusok

Saját domainről kiszolgált betűk, `next/font/local`-lal betöltve (`app/fonts.ts`),
latin + latin-ext (ő, ű) karakterkészlettel:

- `Inter-Variable.woff2` — Inter 4.1, változó vastagság (100–900); alap szövegtípus (`font-sans`)
- `Anton-Regular.woff2` — Anton 400; szekciócímek (`.section-title`)

Mindkettő a SIL Open Font License 1.1 alatt érhető el (https://openfontlicense.org),
ami a weboldalba ágyazást megengedi. Ugyanezek a fájlok vannak az MD Dance School és az MD Dance Company repóban is.
